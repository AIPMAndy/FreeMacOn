01 / Features

简单一点，可靠一点。

普通保活与系统级合盖保活明确分开。只为持续运行任务增加必要的能力。

ϟ

合盖保活

定时系统睡眠覆盖，开启时由 macOS 请求管理员授权，须在目标机型上验证。

◷

按需定时

30 分钟、2 小时、4 小时、8 小时；普通开盖保活可不限时。

▰

电量保护

使用电池且低于或等于 22% 时尝试停止会话，避免继续耗电。

◎

热压力保护

监测 macOS 热压力，达到严重或临界状态时尝试恢复睡眠。

↻

独立恢复机制

守护进程检查会话心跳、超时和系统状态；异常时尝试恢复并回读。

⌘

原生菜单栏

Swift / AppKit，中英文菜单；可选登录启动应用，不默认开启保活会话。

02 / Safety first

保活不是关闭所有保护。

合盖保活会改变系统级睡眠设置。保持明确的授权、可撤销的会话和必要的保护边界。

开发预览 · 真机验收待完成

安全设计

  • 不修改 sudoers、SIP、Gatekeeper 或锁屏设置。
  • 设计为无网络请求、无遥测、无账号。
  • 拒绝接管已有睡眠覆盖；不与其他保活工具同时运行。
  • 恢复失败时提示手动恢复，不承诺所有异常均可自动处理。
阅读安全说明 ↗

必须注意

合盖运行的 Mac 只能放在通风硬质桌面。不要放入电脑包、被褥或封闭空间。先做一分钟合盖及恢复测试，未通过前不要无人值守运行。

GUI 点击、锁屏截图、网络和外设行为需要分别验证。预览版未公证，不能保证适配所有 macOS 和 MacBook 型号。

03 / Get started

从源码开始。

开发预览版，目标 macOS 13 及以上。需要 Xcode Command Line Tools。安装前请先审查源码及安全说明；正式签名、公证的安装包尚未发布。

在 Mac 上构建安装

应用将安装在 ~/Applications；安装脚本不会覆盖现有应用。请先退出其他保活工具。

04 / FAQ

常见问题。

FreeMacOn 和 Amphetamine 是什么关系？

FreeMacOn 是独立的 MIT 开源项目，参考公开技术资料与产品思路，不隶属于 Amphetamine 或 Apple。

可以让 Codex、Claude Code 一直工作吗？

终端进程和本地任务是主要设计场景；工具自身限时、网络中断、锁屏与 GUI 操控限制仍然可能造成中断。请实际验证，不要把保活当作任务成功保证。

为什么合盖模式需要管理员授权？

普通开盖保活只需 caffeinate，合盖模式涉及 pmset 系统级覆盖。项目设计为每次授权，不创建永久免密 sudo 规则。

如果退出后 Mac 仍不睡眠怎么办？

先结束其他保活工具，确认 FreeMacOn 已停止，再运行 sudo pmset -a disablesleep 0，并以 pmset -g 核验。恢复后若仍有残留守护锁请重启。详见安全文档。

是否已经有可直接安装的正式版？

目前为开发预览，原生构建、签名、真实合盖和异常恢复以 GitHub Actions 与真机验收记录为准。尚未提供 Developer ID 签名或公证版。
